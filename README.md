# COBU brand

Brand assets for COBU, a Home & Kitchen brand (@cobugoods).

| Folder | Contents |
|---|---|
| `brand/` | Brand book: `COBU-Brand-Book.pdf` and a web version |
| `logos/` | Wordmark, icon and Instagram profile picture, SVG and high-resolution PNG |
| `instagram/` | Story highlights (1080×1920) and feed posts (1080×1350) |
| `product/` | Product and listing images |
| `tools/` | Scripts that rebuild the logos, brand book and stories |

Opening this repository in Claude Code loads the image and video skills listed in `.claude/settings.json`; `CLAUDE.md` gives Claude the brand rules.
